# Changelog

All notable changes to cognitive-toolworks will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-12-15

### Added
- Multi-source support for skill generation (MCP, OpenAPI, Docs, Scripts)
- AAIF (AI Agent Interchange Format) validation
- Compatibility analysis between platforms
- Example generation for skills
- Documentation source introspection
- Progressive disclosure optimization
- Cross-platform validation (Anthropic, OpenAI)
- Token counting and security scanning
- Type hints and py.typed marker for full type support

### Changed
- Restructured package to `src/cognitive_toolworks/` layout
- Updated CLI commands for better discoverability
- Improved README with PyPI installation instructions
- Enhanced security pattern detection

### Fixed
- Package metadata for PyPI distribution
- Email address in package metadata

## [1.0.0] - 2024-10-25

Initial release with MCP skill generation support.
