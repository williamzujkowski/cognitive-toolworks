# Changelog

All notable changes to the Frontend Performance Optimizer skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-15

### Added
- Initial implementation of frontend-performance-optimizer skill
- Core Web Vitals measurement and analysis (LCP, FID/INP, CLS)
- JavaScript bundle size analysis and optimization recommendations
- Image optimization strategies (WebP/AVIF, responsive images, lazy loading)
- Framework-specific optimization guidance (React, Vue, Angular)
- Browser caching and CDN configuration recommendations
- Performance budget definition and CI integration guidance
- Three-tier procedure (T1: fast path, T2: extended analysis, T3: deep dive)
- Structured output contract with TypeScript interface
- Quality gates for token budgets and determinism
- Comprehensive resource links to official documentation and tools
